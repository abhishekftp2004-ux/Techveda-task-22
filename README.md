# Task 22 — GroupBy Fundamentals (Ultra Expanded)

## Objective
Use Pandas `groupby()` to summarise numerical data across categories and groups.

## Included files
- `Task_22.py`: complete Python script with 10+ examples
- `Task_22.ipynb`: step-by-step notebook
- `superstore_groupby_sample.csv`: synthetic practice dataset
- `region_groupby_summary.csv`: multi-metric regional summary
- `category_profit_summary.csv`: profit statistics by category
- `region_category_sales_summary.csv`: sales by region/category
- `Task_22_GroupBy_Fundamentals_ULTRA_EXPANDED.pdf`: detailed learning guide

## Requirements
Python 3.9+ and Pandas:
`python -m pip install pandas`

## Run
Keep the script and CSV together, then run:
`python Task_22.py`

This is synthetic practice data. Use it to learn the techniques, not to make claims about actual retailers.
